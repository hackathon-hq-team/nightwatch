## ▶️ Как запустить

Учебный проект и два сценария готовы для подключения:
[инструкция для Никиты и Тимура](docs/demo-handoff.md).
Подготовка из корня: `python -m tools.prepare_demo --output .demo-workspace`.
Это начальная проверка механизма; настоящий вызов модели и контейнерная интеграция проверяются отдельно.

```bash
# 1. Клонировать репозиторий
git clone <url>
cd <repo>

# 2. Скопировать переменные окружения и заполнить их
cp .env.example .env

# 3. Установить зависимости и запустить
# (заполнить, когда будет стек)
```
